# AI 应用全栈转型练习区

这个目录用于个人学习和作品开发。

所有学到的知识点统一记录在 [`../复习文档.md`](../复习文档.md)，不创建每日独立复习文件。

规则：

- 不使用公司源码、内部 topic、业务数据或配置；
- 不把公司项目代码复制到个人设备；
- 家庭电脑使用公开资料、合成数据和独立实现；
- 所有练习先自己完成，AI 只用于提示、解释和审查；
- 测试通过不代表真正掌握，还要能够不看代码解释实现。
- 当天未完成“解释、实现、测试/示例”三项验收，不开始下一天；
- 犯错后必须纠正并重新验收，不能记录后直接跳过。
- 一天有多个任务时，每个任务必须单独通过验收；
- 单个任务通过不能代替当天其他任务通过。

## 运行练习

在 `career-learning` 目录执行：

```bash
npm run test:day01
```

如果本机没有安装依赖，也可以执行：

```bash
node --experimental-strip-types --test week01/day01/countUsablePoints.test.ts
```
